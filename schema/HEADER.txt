PIPELINE_DIRECTIVE: losslessly compressed, token-efficient, information-dense, fully detailed, machine-facing; optimized for model parsing over human readability.

USAGE
- This directive governs every pipeline DATA artifact (taxonomies, calibration records, intermediate extractions, specialist payloads) authored or generated by this automation.
- Place it verbatim as the value of the "_directive" field at the top of every pipeline JSON artifact that this project owns.
- EXCEPTION (binding): KB_GENERATION outputs from schema/kb_generator_v1.4.1.txt MUST remain strict JSON whose first non-whitespace char is "{" and last is "}" with additional_properties_allowed=false. A text/field header would violate that contract and the schema's JSON-validity veto dominates. For those outputs the directive is NOT embedded; it is (a) injected into the generation job prompt so generation honors it, and (b) recorded in the run manifest alongside the artifact. See PLAN.md "Header reconciliation".
