# GK + Combination study guide (PDF)

`CA-CDL-General-Knowledge-and-Combination-Study-Guide.pdf` (124 pages, US Letter):
1. The 50 most-missed facts (from `source/lessons/00-START-HERE.md`)
2. Easy to confuse: handbook-way table, look-alike numbers, opposite-answer pairs
3. 18 hard topics explained with diagrams and worked examples
4. All 18 GK/CV lessons: key points, numbers, exam traps (High-weight lessons first, then by most-missed count)
5. Practice tests: 50 GK + 20 CV questions from the lessons, answer key with explanations
6. Glossary and test-day checklist

Facts come from `app/src/content/content.json` (the same verified content as the app); the explainers in `build.py` restate lesson facts only.

Rebuild: `npm ci` in `app/`, `pip install pymupdf`, then `./build.sh`.
