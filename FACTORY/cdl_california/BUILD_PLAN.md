## Learning engine (`src/engine/`, pure TS, unit + simulation tested) — spec persisted to `research/ENGINE_SPEC.md`
- **Evidence classes**: `mcq(w .3) | tf(.2) | typed(1.0) | selfgrade(flashcard/TYK, 2-button Again/Good) | interactive_check(untimed widget check, .5) | explore/timed(quarantined, no model write) | mock`. Widgets emit `onEvidence(class, kuIds, correct)`.
- **FSRS-6** (ts-fsrs, retention 0.90, `maximum_interval` capped at days-to-exam, fuzz on; golden tests pin `now`). Grade: wrong/"don't know"→1; correct + "guessed" toggle (set before feedback)→1; correct slow (rt per char of stem+options > 2× rolling median; ignored first 20 answers)→2; correct→3; MCQ never 4.
- **BKT per concept**: P(L0)=0.3 (placement can raise), S=0.1, G by format (1/3, .5, .05), tempered odds update `LR^(w·e)` (easy-item damping on correct only). Acceptance: single correct MCQ **evidence-update** Δ≤+0.07 at P(L)=0.2; learning transition P(T)=0.15×w applied once per concept per day at session close only if a correct answer occurred. Real gate = synthetic learners.
- **Diagnosis MVP** (deterministic from tags): **N** number-confusion (numeric distractor; ≥2 in family → confusion pair), **T** trap-wording (neg-stem/T-F miss while positives OK, or trap_named), **W** wrong-source (alt_source), **E4** retrieval decay (R<0.8). v1.1: E1 slip, E2 misconception, E3 prerequisite (needs prereq edges). Uncertainty gate: <3 attempts → probe first.
- **Remediation**: N→number-family table + memory hook + typed cloze + interleaved confused pair; T→flip drill ×3 + "read twice" highlight; W→"Handbook way" contrast card + 2 alt_source MCQs, retest 3 d; E4→FSRS relearn.
- **Mistake notebook**: upsert per (concept,cause); priority = stakes(High 2/Med 1)×(1−P(L))×(1+[R<0.9]); open→probing→resolved after ≥2 correct probes on distinct days incl. ≥1 typed/T-F where available + P(L)≥0.6; manual = snooze.
- **Planner**: class→tests, exam date/test, minutes/day, off-days; new-material cutoff = exam − max(2, ceil(0.2·days)); order GK-01→14→CV-01→04; final-review injection so R(exam)≥0.9; mocks at ~60% + last 2 days; feasibility go/tight/no-go. Daily queue: overdue high-stakes → notebook probes → new lesson segment → interleaved mix.
- **Calendar**: planned frozen at first open of day; fill `floor(min(done/planned,1)×20)×5`% with min 5% if any work; tick only at 100%; planned=0 → rest state; future = dashed forecast; rollover 03:00 local; "days active in last 30".
- **Gates**: next lesson unlocks at lesson practice ≥90% or placement (navigation convenience; reviews never blocked). Concept rings = BKT states Not started/Familiar/Proficient/Mastered (can drop).
- **Readiness**: on-device Monte Carlo (10k draws): sample 50/20 KUs under ≥2 weighting schemes (lesson weight; uniform) + latent offset θ~N(0,σ); p=σ(a·logit(R)+b) (Platt-fit on held-out mocks after ≥2 mocks; prior otherwise); show band from **lower bound** (Not yet / Borderline / Likely ≥0.9) + range; Brier after each mock. "**Strong ready**" badge = 2 consecutive held-out mocks ≥90%. Elo deferred (prior p from trap/number flags).

## Verification & scoring protocol
- Objective: `npm run parse && python3 scripts/validate_content.py` ALL GREEN; `npx vitest run` (parser golden, FSRS golden, BKT acceptance, diagnosis w/ planted truth, readiness MC vs binomial reference Bin(50,.9)≥40=0.9906, calendar edges, export/import round trip, ID migration).
- E2E Playwright 1.56.1 (desktop 1280×800, mobile 390×844; `page.clock.install` before goto, `setSystemTime`+reload, `animations:'disabled'`): onboarding A/B/C → lesson core→deep → widget → practice w/ planted wrong answers → notebook shows expected cause → reload resumes exact spot → +3 days → due reviews + calendar % → full 50Q GK mock w/ skip-return → export → clear → import → identical state. Single-file via file:// + **sandbox harness** (iframe `sandbox="allow-scripts allow-popups"`, storage failure → memory fallback + resume code). PWA offline on localhost only (SW controller, route-abort, reload, `fromServiceWorker`). axe: 0 serious/critical. Iterations mobile-light only; full matrix (2 viewports × light/dark) at gates.
- **Evaluator loop** (anti-inflation): evaluators = fresh agents seeing only screenshots/DOM text/test output/rubric/anchors, blind to round and builder claims; **objective dims computed by formula** (fidelity = validator+audit, continuity = E2E, a11y = axe+keyboard, readiness honesty = sim metrics); LLM judges only teaching, visual, gamification, guidance; median of 3 (4th if spread >2), log min; each ≥8 must cite ≥3 observations + ≥2 remaining defects; score can't rise if artifact hash unchanged; **canary build** with seeded defects (4/32↔2/32 key swap, 390 px overflow, 3:1 contrast, "fifth wheel level") — missed canary voids scores; unbuilt features = N/A; ≤3 rounds/gate then ship with documented gap (hard fails always block).
- **Knowledge-blind personas** (never-seen-a-truck Class A, Class B beginner, returning learner): answer only from on-screen text; measure comprehension + friction.
- Rubric (weights): Handbook fidelity 15 · Understanding-first teaching 15 · Interactive visuals 10 · Adaptive review & diagnosis 10 · Honest readiness 8 · Class path + end-to-end guidance 10 · Plain-language accessibility 10 · Topic-specific non-manipulative gamification 7 · Continuity 7 · Visual/UX polish 8. **Pass = every dim ≥8 AND weighted ≥8.0.** Hard fails (cap 5): key contradicts handbook; invented URL/ID shown as verified; game writes learner model; FSRS nondeterminism under pinned clock; progress loss on reload.
- Final report: scorecard per gate/round, errata vs lessons, unverifiable items, known limits.
