## Precautions in force (why you can trust the output)

- **Gates, not opinions:** every artifact must pass deterministic Python validators; the integrator re-runs them from its OWN copies (a builder can't grade itself).
- **Different brains check each other:** the three agents are three model families; each build is cross-verified by a different one — research calls this the 'universal antidote' to agents agreeing themselves into being wrong.
- **Fresh, short context per task:** builders start each job from a tight digest, not a giant history, because models degrade before their window fills.
- **The repo can't command the agents:** only signed, authenticated task messages from the integrator are instructions; everything else in the repo is treated as untrusted data.
- **Real enforcement is outside the AI:** sandboxes, permission rules, and gates stop bad actions — not just written 'don't' rules (which research shows can backfire).
- **Self-reported 'done' is never trusted:** acceptance needs a passed gate plus the integrator's independent re-check.
