## Actual defect (ordered)

1. **Primary — wrong Grok CLI shape (exit 2 every WAKE)**  
   Wrapper invoked:
   ```
   grok agent --cwd "$REPO" --rules ... --max-turns 40 -p "..."
   ```
   Top-level `grok` owns `--cwd` / `--prompt-file` / `--max-turns` /
   `--always-approve`. Subcommand `grok agent` does **not** accept `--cwd`.
   `poll.log` spam (every 5 min on tip change):
   ```
   error: unexpected argument '--cwd' found
   Usage: grok agent [OPTIONS] [COMMAND]
   ```
   Model never ran → MRC≠0 → **tip never advanced** → permanent WAKE loop on
   the same tip → looked like “no automatic work,” while ticks still ran.

2. **Secondary — empty `last_wake`**  
   Install created a 0-byte `last_wake` and never wrote a timestamp after a
   successful model tick (because model never succeeded). Heartbeat backstop
   and “last successful wake” bookkeeping were broken. Gate now treats empty
   `last_wake` as first-run; wrapper writes an ISO timestamp on MRC=0.

3. **Tertiary — silent launchd stdio**  
   Wrapper only wrote to `poll.log`, so `launchd.out.log` / `.err.log` stayed
   0 bytes even while ticks ran. Fixed: every tick logs `TICK start` to
   `poll.log`; IDLE/WAKE one-liners also echo to stdout → launchd.out.

PATH was **not** the primary killer: plist already included
`~/.grok/bin` (where `grok` lives) and `/usr/bin` (`git`). Still hardened:
absolute `GROK_BIN` / `GIT_BIN`, expanded PATH including `/opt/homebrew/bin`.
