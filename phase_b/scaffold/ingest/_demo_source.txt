Low-Rank Adaptation of Large Language Models

LoRA freezes the pretrained model weights and injects trainable rank-decomposition
matrices into each transformer layer, drastically reducing the number of trainable
parameters for downstream tasks. Because the original weights stay frozen, multiple
LoRA adapters can be served from one base model and swapped per request.

QLoRA extends this by quantizing the frozen base model to 4-bit (NF4) while keeping
the LoRA adapters in higher precision, so a 65B model can be fine-tuned on a single
48GB GPU. The key risks are calibration of the quantization and adapter rank choice.

Monitored training with rollback

During fine-tuning, an eval-in-the-loop protocol scores held-out tasks on a fixed
cadence. If the monitored score stalls or regresses for a patience window, training
rolls back to the best checkpoint and prunes the neutral last-N steps before resuming
with adjusted hyperparameters. This bounds wasted compute and prevents reward drift.
