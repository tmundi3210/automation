# GLOSSARY · the abbreviation key for the dense memory grammar

conf            confidence in [0,1] on a belief/claim (estimate, not measurement)
epistemic       uncertainty reducible with more evidence
aleatory        irreducible noise — flagged DO-NOT-CHASE (don't try to learn it away)
runs-seen       how many runs contributed to a belief (confidence earned by repetition)
≥N-origin gate  genuine hype requires ≥N independent origins (default N=3), independent of volume
medium-tier     the rising-but-not-saturated opportunity band (a HYPOTHESIS, re-measured per domain)
VoI             value of information = goal-impact × uncertainty ÷ answer-cost
Brier           prediction error score = (confidence − outcome)²; lower is better-calibrated
ECE             expected calibration error; we require < 0.05 on any number that gates a decision
ABLATE          drop borrowed bindings to test if lift is ACQUIRED skill vs BORROWED prior
the gate        the fail-closed compliance check (../GATE_STEP2.md); sole predecessor of publish
